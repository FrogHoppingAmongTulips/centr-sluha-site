# Вектор — центр медицинской реабилитации

Современный многостраничный сайт центра медицинской реабилитации на **React + Vite**.
Дизайн в стиле «медицинский премиум»: спокойная палитра, крупная типографика, аккуратные карточки услуг и клиник.

## Страницы
- **Главная** — hero, статистика, направления, преимущества, этапы, клиники, отзывы, CTA
- **Услуги** — направления реабилитации и этапы лечения
- **О центре** — миссия, цифры, принципы, команда
- **Клиники** — карточки локаций с контактами
- **Контакты** — форма заявки и реквизиты

## Запуск
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Стек
React 18 · React Router 6 · Vite 5 · чистый CSS (без UI-фреймворков)
