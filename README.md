# Демо-сайт центра слухопротезирования

**Сайт открыт:** https://froghoppingamongtulips.github.io/centr-sluha-site/

Ссылку видит только тот, кому её дали: страница закрыта от поисковиков (`robots.txt` и `noindex`), в Яндексе и Google не появится. Исходники лежат в этом приватном репозитории, наружу уходит только собранная версия — в отдельный репозиторий [centr-sluha-site](https://github.com/FrogHoppingAmongTulips/centr-sluha-site).

Многостраничный сайт на **React + Vite**: витрина центра слуха с каталогом аппаратов, услугами, центрами, статьями и формами заявки.

Контент демонстрационный:

- модели аппаратов, характеристики, цены и **фотографии** взяты из обзора [expertology.ru «13 лучших слуховых аппаратов»](https://expertology.ru/13-luchshikh-slukhovykh-apparatov/) — для боевого сайта нужны свои снимки или разрешение правообладателя;
- набор разделов, услуг и блоков — по структуре [ssluha.ru](https://www.ssluha.ru/);
- контакты настоящие: +7 (913) 821-73-47, kostochkodebildmitriy@gmail.ru, Томск, Иркутский тракт, 33 (Октябрьский район);
- название центра, имена врачей, отзывы и цены на услуги **вымышлены**;
- лицензий, сертификатов и реквизитов на сайте нет — только предупреждение «имеются противопоказания»;
- фото аппаратов лежат в `public/img/`, остальные снимки — чёрные блоки (`src/components/Ph.jsx`), логотип — SVG в `src/components/Logo.jsx`.

Чтобы поставить фото врача: положите файл в `public/img/` и пропишите путь в поле `img` нужного врача в `DOCTORS` (`src/data/site.js`), например `img: '/img/doctor.jpg'`. Пока фото нет — на их месте чёрные блоки.

Весь текст и все цифры правятся в одном файле — `src/data/site.js`.

## Структура сайта

| Раздел | Маршрут | Что внутри |
|---|---|---|
| Главная | `/` | визитка: первый экран со снимком и карточкой, быстрые ссылки, «кто мы» с цифрами, разделы сайта, адрес с картой и мессенджерами, форма записи |

## Формы

`src/components/RequestForm.jsx` — три варианта:

- `visit` — запись: имя, телефон, цель визита, дата, время, комментарий;
- `ask` — вопрос: имя, телефон, почта, текст;
- `call` — обратный звонок: имя, телефон, удобное время.

Открываются на страницах и в модальном окне: `useRequestForm()` → `openForm('call' | 'visit' | 'ask', slug?)`.

Сервера у сайта нет, поэтому форма не делает вид, что отправила заявку: она собирает
текст обращения и предлагает отправить его сообщением на рабочий номер, письмом или
позвонить. Когда появится CRM или почтовый сервис, в `RequestForm.jsx` останется
один запрос вместо трёх ссылок.

## Корзина

`src/components/CartContext.jsx` — список отложенных моделей без количеств: это не интернет-магазин, а подбор моделей к примерке. В шапке при непустом списке горит точка.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
npm test         # прогон проверок по собранной версии
npm run deploy   # собрать и обновить опубликованный сайт
```

## Панель управления

Содержимое сайта может приходить из панели (Directus): товары, услуги, акции,
новости, центры, контакты — и туда же падают заявки с форм.

- клиент панели: `src/lib/panel.js`, общий источник данных: `src/components/ContentContext.jsx`;
- адрес панели задаётся в `.env.local`: `VITE_PANEL_URL=http://localhost:8055`;
- переменная не задана — сайт работает на встроенных данных из `src/data/site.js`,
  а заявки предлагает отправить сообщением или письмом.

Панель лежит рядом, в `projects/panel` (в репозиторий не входит). Запуск —
файл «ЗАПУСК ПАНЕЛИ.command», инструкция для владельца — `ПАМЯТКА.md`.

## Публикация

`npm run deploy` собирает проект с адресом `/centr-sluha-site/` и отправляет содержимое `dist/`
в репозиторий [centr-sluha-site](https://github.com/FrogHoppingAmongTulips/centr-sluha-site),
откуда его раздаёт GitHub Pages. Обновление появляется на сайте через минуту-две.

Папка `dist/` — отдельный git-репозиторий (в основном она в `.gitignore`), поэтому исходники
остаются приватными: наружу уходят только собранные файлы.

Сайт закрыт от индексации: `public/robots.txt` запрещает обход, в `index.html` стоит `noindex`.
Пароля на входе нет — доступ у всех, кому дали ссылку.

Прямые ссылки на внутренние страницы работают через `404.html`: GitHub Pages отдаёт её вместо
несуществующего файла, приложение читает адрес и открывает нужную страницу.
