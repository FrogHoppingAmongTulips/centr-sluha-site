# Вектор — центр слуха и реабилитации

Современный многостраничный сайт центра слухопротезирования на **React + Vite**.
Тематика: диагностика слуха, подбор и настройка слуховых аппаратов, детская сурдология, помощь людям с инвалидностью по слуху (льготы, сертификаты ИПРА).
Дизайн в стиле «медицинский премиум»: спокойная палитра, крупная типографика, аккуратные карточки услуг и центров.

## Страницы
- **Главная** — hero, статистика, услуги, преимущества, этапы, центры, отзывы, CTA
- **Услуги** — диагностика, аппараты, настройка, детская сурдология, реабилитация, сервис
- **О центре** — миссия, цифры, принципы, команда сурдологов
- **Клиники** — карточки центров слуха с контактами
- **Контакты** — форма записи на проверку слуха и реквизиты

## Запуск
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Стек
React 18 · React Router 6 · Vite 5 · чистый CSS (без UI-фреймворков)
